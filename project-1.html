Dynamic System Modeling at John Deere

Built comprehensive Simulink and MATLAB models for GNSS guidance systems. Implemented advanced IMU noise modeling using Allan deviation analysis. Designed and executed unit tests for cross-platform navigation framework integration.

Project Overview

At John Deere, I developed dynamic system models in Simulink and MATLAB using object-oriented programming to support guidance system testing and controls algorithm optimization. The models streamlined the design decision process and accelerated algorithm validation across multiple platforms.

Key accomplishments included self-taught IMU noise modeling using Allan deviation analysis and Gauss-Markov processes to characterize sensor instability. I developed comprehensive unit tests and performance monitoring systems for early detection of issues in model subsystems and overall performance, enabling rapid diagnostics and continuous improvement of the navigation framework.
